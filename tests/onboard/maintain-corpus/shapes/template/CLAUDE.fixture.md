# Acme

Acme is a small web app.

## Tech Stack

- Next.js 15
- TypeScript

## Commands

### Development

- `npm run dev` — Start the dev server
- `npm run build` — Production build

### Quality

- `npm run lint` — ESLint
- `npm test` — Run the unit tests

## Conventions

- Keep functions pure.
- Prefer server actions over API routes.
